# Setu Implementation Status (STATUS.md)

This document tracks every requirement and failure fix in Setu, its status (`done`, `partial`, `not done`), the automated test that proves it, and its **Evidence Class**:
- `browser-e2e`: Real headless browser automation (Playwright driving Chromium against live servers and IndexedDB)
- `api-integration`: Live API client tests against FastAPI routes and SQLite database
- `unit`: Pure in-memory unit tests
- `simulation-only`: Algorithmic synthetic learner evaluations with deterministic seeds
- `manual-unverified`: Explicit human disclosures / documentation
